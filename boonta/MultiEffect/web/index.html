editor, librarian and preview

Bank

16 slots, program change 0-15

    Parameters

    Drag a knob, or use the arrow keys. Double-click resets it.

    Chain

    Page on the pedal

    CC 119 — which page the LEDs and pots address. No effect on the sound.

    Toggles

    Physical switches. Not in the MIDI map and not in a preset — set these to match your pedal so the preview agrees with it.

    Preview

    The firmware's DSP, ported to a worklet.
    in
    out

    Nothing running.

    Traffic is one way. The firmware has a MIDI in and no out, so nothing here can read the pedal back — this shows what has been sent, not what has been received. A knob turned on the pedal changes the pedal and not this.
